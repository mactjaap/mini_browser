Mini Browser 2.1

Welcome to Mini Browser, a small text-oriented web browser for the WHY2025 badge. Version 2.1 supports links, bookmarks, Back/Forward history and simple GET forms.

Search the small web

Wiby is a search engine focused on simple, lightweight websites and is a good match for Mini Browser.

How to browse

Links and form controls have numbers. Type a number and press Enter to activate it. You can also use Tab and Shift+Tab to select actions.

Use the Up and Down arrows to scroll. Hold an arrow key for continuous scrolling. J and K also scroll one line at a time.

Browser keys

  • WHY+E - enter a new URL
  • WHY+C - edit the current URL
  • WHY+H - home
  • WHY+R - reload
  • WHY+B - back
  • WHY+G - forward
  • WHY+F - add or remove bookmark
  • WHY+M - bookmarks
  • WHY+Q - quit

About

Mini Browser intentionally has no JavaScript engine, CSS layout engine or image renderer. It is designed for ordinary HTML, text content, links and simple GET forms.
