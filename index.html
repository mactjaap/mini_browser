Mini Browser 2.3

Welcome to Mini Browser, a small text-oriented web browser for the WHY2025 badge. Version 2.3 supports links, bookmarks, Back/Forward history, simple GET forms, broad Unicode, monochrome emoji and real bold text.

How to browse

Links and form controls have numbers. Type a number and press Enter to activate it. Use Up and Down to scroll; hold an arrow for continuous scrolling. J and K also scroll one line at a time.

Browser keys

  • WHY+E - enter a new URL
  • WHY+C - edit the current URL
  • WHY+H - home
  • WHY+R - reload
  • WHY+B - back
  • WHY+G - forward
  • WHY+F - add or remove bookmark
  • WHY+M - bookmarks
  • WHY+Q - quit

About 2.3

Mini Browser 2.3 keeps the built-in ASCII font and optionally supports an external Unicode font. HTML b and strong text are rendered as genuine bold text.

Unordered list markers deliberately remain ASCII * characters, so basic list rendering does not depend on the external Unicode font.

Mini Browser intentionally has no JavaScript engine, CSS layout engine or image renderer. It is designed for ordinary server-rendered HTML, text content, links and simple GET forms.
