Mini Browser

A text-only web browser for the WHY2025 badge.



SPECIAL KEYS
RED Square: NPR Text
ORANGE Triangle: Hacker News
YELLOW Cross: textfiles.com
GREEN Circle: What is my IP
BLUE Cloud: Bobcat Browser
PURPLE Diamond: Curl



WHY KEY (hold WHY, then press)
E = edit URL   H = home   R = reload
B = back   Q = quit



NAVIGATE
Type a URL and press Enter.
Tab / Shift-Tab pick a link, Enter opens it.
Up/Down or J/K scroll. PageUp/PageDown by page.



RECOMMENDED
Wikipedia (mobile)
OpenBSD
SQLite Docs
Linux Man Pages
RFC Editor



GOOD TO KNOW
Text only: no CSS, JavaScript, or images.
Max 64 KB per page. Bare hostnames become https.
Full guide: readme.html
