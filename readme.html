Mini Browser 1.6

A compact, text-oriented web browser for the WHY2025 badge.

Mini Browser is a lightweight browser written in C using SDL and libcurl. It retrieves HTML pages, converts them into readable text, extracts links, and provides a keyboard-driven browsing interface designed specifically for the WHY2025 badge.

It is intentionally small and simple: no JavaScript, no CSS engine, no images, and no attempt to behave like a modern desktop browser.



Features

  • Text-based web browsing
    Downloads HTML pages and converts them into readable text for the badge's 720x720 display.
  • Link navigation
    Links are extracted from the page.
    Use Tab / Shift+Tab to select a link and Enter to open it.
  • URL editor
    Type a URL directly into the address bar.
    The editor supports cursor movement, insertion, Backspace and Delete.
    Bare hostnames are automatically expanded, for example: example.org -> https://example.org
  • Redirect handling
    Standard HTTP redirects are followed automatically.
  • Relative URL resolution
    Handles common relative URLs such as /path, ./path, //host/path, query strings and fragments.
    Complex ../ path normalisation is still limited.
  • Entity decoding
    Decodes common HTML entities including &amp;, &lt;, &gt;, &quot;, &#39; and &nbsp;.
  • Page titles
    Extracts the HTML title and displays it in the top bar.
  • HTTP status
    Displays the HTTP status together with the page title.
  • Error handling
    Network and HTTP failures are shown as readable error pages.
  • Keyboard-only interface
    Fully controlled using the WHY2025 badge keyboard.


Bookmarks

Version 1.6 adds persistent bookmarks.

  • WHY+F - add the current page to bookmarks
  • WHY+F again - remove the current page from bookmarks
  • WHY+M - open the bookmarks page

After adding or removing a bookmark, Mini Browser briefly displays:

BOOKMARK ADDED

or:

BOOKMARK REMOVED

The bookmarks page uses the normal Mini Browser navigation system. Use Tab / Shift+Tab to select a bookmark and Enter to open it.

Up to 32 bookmarks can currently be stored. Both the page title and URL are saved.

Bookmarks are stored in:

APPS:[mini_browser]bookmarks.txt

Bookmarks survive quitting Mini Browser, restarting the application, rebooting the badge, and completely powering the badge off and on.

Note: flashing the complete BadgeVMS firmware replaces the application storage image and therefore removes saved bookmarks.



Keyboard Controls

  • Typing - enter or edit a URL
  • Enter - navigate to the typed URL or open the selected link
  • Backspace - delete before the URL cursor
  • Delete - delete at the URL cursor
  • Left / Right - move the URL cursor
  • Down / J - scroll down
  • Up / K - scroll up
  • PageDown / PageUp - scroll a page at a time
  • Home - jump to the top of the page
  • Tab - select next link
  • Shift+Tab - select previous link
  • Enter - open selected link

WHY key shortcuts - hold the WHY (0xE3) key and press:

  • E - Edit: start a new URL prefilled with https://
  • C - Current: edit the current URL
  • H - Home: go to the Mini Browser home page
  • R - Reload the current page
  • F - add/remove current page as a bookmark
  • M - open bookmarks
  • B - go back
  • Q - quit Mini Browser

When the bookmarks page is open, WHY+B returns to the webpage you were viewing before opening bookmarks.



Special Keys

The dedicated coloured WHY2025 badge keys provide instant navigation:

  • [SQUARE / RED] -> NPR Text
  • [TRIANGLE / ORANGE] -> Hacker News
  • [CROSS / YELLOW] -> textfiles.com
  • [CIRCLE / GREEN] -> What is my IP address?
  • [CLOUD / BLUE] -> Bobcat Browser
  • [DIAMOND / PURPLE] -> curl


User Interface

The interface is intentionally minimal.

The top bar can display:

  • the current URL
  • the HTTP status
  • the page title
  • the currently selected link
  • temporary status messages

The top-left contains a cyan square with a yellow magnifying-glass icon.

The rest of the display is used for the text representation of the current webpage.



Implementation Overview

  • Fetch: pages are retrieved using libcurl, with a default maximum page size of 64 KB.
  • Parse: a small custom HTML parser:
    • skips non-visible head content
    • skips script and style content
    • recognises common HTML block elements
    • collapses whitespace
    • decodes common HTML entities
    • extracts page titles
    • extracts and indexes links
  • URLs: lightweight absolute and relative URL resolution.
  • Wrap: text is wrapped to fit the viewport using a fixed 5x7 bitmap font.
  • Render: SDL draws the address bar, separators and text viewport.
  • Bookmarks: bookmarks are kept in RAM while Mini Browser is running and written to the BadgeVMS filesystem whenever they change. They are loaded again when Mini Browser starts.


Known Limitations

  • No JavaScript
  • No CSS rendering
  • No images
  • No forms
  • No cookies or login sessions
  • ASCII-focused rendering - unsupported characters may be simplified to ?
  • Content cap - maximum downloaded page size is 64 KB
  • Link cap - maximum 128 extracted links per page
  • Bookmark cap - maximum 32 bookmarks
  • Relative URLs - complex ../ traversal is not fully normalised
  • Firmware flashing - a complete BadgeVMS firmware flash removes saved bookmarks

Simple HTML and text-oriented websites work best.
