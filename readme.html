Mini Browser 2.1

Mini Browser is a compact, interactive, text-oriented web browser for the WHY2025 badge. It is written in C using SDL3 and libcurl.

Version 2.1 is a stable release. It supports normal links, simple GET forms, persistent bookmarks, Back/Forward history, URL editing, hold-to-scroll and text rendering of common HTML structures.

What Mini Browser is

Mini Browser downloads HTML and converts it directly into a compact text page suitable for the 720 by 720 badge display. Links and interactive form controls are assigned numbers so the entire browser can be operated from the keyboard.

It deliberately avoids the complexity of a modern graphical browser. There is no JavaScript engine, CSS layout engine or image renderer.

Simple HTML forms

Mini Browser 2.1 can use simple GET forms. Supported input types are text, search, url, hidden and submit. Submit buttons made with the button element are also supported.

A simple form can appear as:

[1] q:
[2] [Search]

Type 1 and press Enter to edit the field. Type your search text and press Enter again to store it. The browser stays on the same page. Then type 2 and press Enter to submit the form.

Form editing is separate from URL editing. Text typed into a form field therefore does not accidentally become the browser URL.

GET form data is URL encoded. Spaces become plus signs and unsafe characters are percent encoded. Hidden fields are submitted, disabled fields are ignored, and a named submit button is included when that button is used.

Forms whose action already contains a query string are handled correctly by adding new parameters with an ampersand.

Mini Browser can keep up to 4 forms on a page and up to 8 fields in each form.

POST forms are recognised but are not submitted. Mini Browser displays "POST FORMS NOT SUPPORTED".

Textarea, select menus, checkboxes, radio buttons, file uploads and JavaScript-driven forms are not currently supported.

Links and actions

Links and visible form controls share one numbered action system. Up to 160 actions can be represented on a page, including up to 128 hyperlinks.

Type an action number and press Enter, or use Tab and Shift+Tab to move through the available actions and press Enter to activate one.

HTML rendering

Mini Browser understands useful structure from ordinary HTML, including:

  • headings
  • paragraphs and common block elements
  • line breaks
  • ordered and unordered lists
  • preformatted text
  • inline code
  • bold and strong text
  • emphasis and italic text
  • horizontal rules
  • simple table rows and cells
  • links
  • simple forms
  • common HTML entities
  • decimal and hexadecimal numeric entities

Comments, doctypes, scripts, styles and normal head content are ignored while rendering. The HTML title is extracted separately and can be shown in the top bar.

Scrolling

Press Up or Down to move one line. Holding either arrow starts continuous scrolling after a short delay. J and K provide one-line scrolling without key repeat. Page Up and Page Down provide larger movements.

URL editing

Press WHY+E to start a new address beginning with https://. Press WHY+C to edit the current URL.

While editing, Left and Right move the cursor, Backspace and Delete remove characters, Home moves to the beginning and End moves to the end. Press Enter to navigate.

If a typed address has no URL scheme, Mini Browser automatically adds https://.

History

Press WHY+B to go Back and WHY+G to go Forward. Mini Browser keeps up to 32 history entries.

If you go Back and then navigate to a new page, the old forward branch is discarded, as in a conventional browser. Reloading does not create another history entry. A successful GET form submission is normal navigation and therefore also participates in Back and Forward history.

Bookmarks

Press WHY+F to add the current page to bookmarks. Press WHY+F again on the same URL to remove it.

Press WHY+M to open the local bookmark page. Up to 32 bookmarks are stored persistently in BadgeVMS storage. 

APPS:[mini_browser]bookmarks.txt

Keyboard reference

  • number + Enter - activate numbered action
  • Tab - next action
  • Shift+Tab - previous action
  • Up / Down - scroll; hold for continuous scrolling
  • J / K - one-line scrolling
  • Page Up / Page Down - larger scrolling
  • WHY+E - enter new URL
  • WHY+C - edit current URL
  • WHY+H - home
  • WHY+R - reload
  • WHY+B - back
  • WHY+G - forward
  • WHY+F - add/remove bookmark
  • WHY+M - bookmarks
  • WHY+Q - quit

Network behaviour

Mini Browser uses libcurl and HTTP/1.1 where available. Redirects are followed up to a bounded limit. The browser requests identity transfer encoding rather than compressed page data.

Connection failures are shown as readable error pages. HTTP status errors such as 404 and 500 are also displayed explicitly.

Resource limits

  • downloaded page data - 64 KiB
  • URL - 256 bytes
  • links - 128
  • interactive actions - 160
  • forms - 4 per page
  • form fields - 8 per form
  • editable form value - 127 characters
  • bookmarks - 32
  • history entries - 32

These bounded limits keep memory usage predictable on the embedded badge.

Unsupported web features

Mini Browser does not currently implement:

  • JavaScript
  • CSS layout and styling
  • images
  • audio or video
  • POST form submission
  • complex form controls
  • file uploads
  • modern browser application APIs
  • a complete HTML5 DOM and parser
  • a full Unicode font

Simple server-rendered websites and text-oriented sites work best.

Implementation

The main processing path is intentionally small:

URL
 |
 v
libcurl fetch
 |
 v
HTML-to-text parser
 |
 +-- links
 +-- forms
 +-- title
 |
 v
numbered actions
 |
 v
text wrapping
 |
 v
SDL3 renderer

A numbered action can represent a hyperlink, an editable form field or a form submit button. This lets the same keyboard navigation mechanism operate all interactive content.
